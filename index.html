Syntax

# Title          new table
## Subtitle     kicker under the title
> Intro        how-to-use paragraph
1. Text        entry (any number)
1-5. Text      range instead of a number
  1-5. Text    indent 2 = sub-roll of the entry above
- Text         entry, auto-numbered
+4. Text       featured (mosaic layout)
**Label.** …   run-in bold label
~ Text         italic rider line
: Text         indented sub-roll block
%layout two    per-table override
%die d30       force the die chip
%cols A | B    column headings (compound)
%at 3          mark step 3 (track / ratchet)
blank line       = new paragraph
**b** *i* __u__ ^^sc^^
